## 📌 About The Project

**FreshBasket** is a front-end grocery e-commerce website designed to provide a simple and user-friendly shopping experience.

The project allows products to be managed through an owner/admin dashboard. Products can be **added, edited, deleted and stored locally** using the browser's `localStorage`.

The application includes grocery categories such as **Spices, Grains & Pulses, Dairy & Eggs, Fruits & Vegetables, Baking, and Oils & Condiments**.

---

## ✨ Features

### 🛍️ Product Management

* ➕ Add new products
* ✏️ Edit existing products
* 🗑️ Delete products
* 📦 Manage product stock
* 💰 Manage product prices
* 🏷️ Manage product categories
* 📝 Add product descriptions
* 🖼️ Add product images

### 💾 Local Storage

Product information is stored in the browser using **localStorage**, so the data can remain available after refreshing the page.

### ⚠️ Stock Management

Products with low stock are automatically highlighted to make stock management easier.

### 🎨 Category Support

The project supports multiple grocery categories:

* 🌶️ Spices
* 🌾 Grains & Pulses
* 🥛 Dairy & Eggs
* 🥬 Fruits & Vegetables
* 🍞 Baking
* 🫒 Oils & Condiments

## ⚙️ How It Works

### 1️⃣ Product Initialization

When the application runs for the first time, sample grocery products are loaded automatically.

Example products include:

* Organic Turmeric Powder
* Basmati Rice
* Farm Fresh Eggs
* Heirloom Tomatoes
* All-Purpose Flour
* Extra Virgin Olive Oil
* Green Cardamom
* Red Lentils

### 2️⃣ Add Product

The admin can enter:

* Product name
* Price
* Unit
* Category
* Stock
* Image
* Description

and add the product to the store.

### 3️⃣ Edit Product

Existing products can be edited whenever product information needs to be updated.

### 4️⃣ Delete Product

Products can be removed from the store using the delete option.

### 5️⃣ Data Storage

Product information is saved using:

```javascript
localStorage
```

This allows product data to persist in the browser.
